# Для кого это всё

**Создано:** 2026-11-13  
**ID:** 0001  
**Статус:** черновик  
**Роль:** рамка для остальных заметок и будущей книги  
**Связанные skills/specs:** нет связей  

Создано для коллег, новых членов команды, агентов и всех читателей этого репозитория, которым интересна тема разработки на Golang.

## Аудитории

1. **Коллеги** — единый источник истины по кодстайлу и подходу к разработке.
   Что получают: понимание, как создавать проект с нуля, как внедрять новые
   модули, и синхронизацию подхода между участниками.

2. **AI-агенты** — skills для автоматизации разработки.
   Что получают: skills/ для создания проекта с нуля, внедрения новых модулей
   и пересоздания примеров в этом репозитории.

3. **Читатели** — рассуждения и примеры для изучения Go.
   Что получают: заметки с объяснениями, примеры кода и скиллов.

## Что отсюда следует

- skills/ — для коллег и агентов; рассуждения туда не попадают.
- specs/ — ТЗ для примеров в этом репозитории; ссылаются на skills, не наоборот.
- drafts/ и book/ — для читателей; не источник истины для агента.
- skills/ должны быть самодостаточны: коллега скачивает их в свой проект, где нет ни specs/, ни drafts/.
- AGENTS.md в этом репозитории — для внутреннего агента (пересоздание примеров), а не для агента коллеги.
- src/ — рабочий код; примеры в книге — иллюстрация, это разные артефакты.
