# Drafts

Черновики и заметки для будущей книги. **Не источник истины.**
Правила — в skills/, задания — в docs/specs/, объяснения — в docs/design/.

## Правила раздела

- Формат: `NNNN-kebab-case.md`, четырёхзначный сквозной номер.
- Номер присваивается при создании и **не меняется** при переезде
  в тематический каталог.
- Номер — это стабильный ID заметки. Ссылки из книги и specs указывают на номер, а не на путь.
- «Дыры» в нумерации внутри тематического каталога — нормальны.
