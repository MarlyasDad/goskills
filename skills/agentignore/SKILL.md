# .agentignore

Навык отвечает на вопрос «**что агент не должен читать**». Вопрос «что не
коммитить» — в `skills/gitignore`.

## Файл

- Имя — `.agentignore`, лежит в **корне проекта**, рядом с `go.mod`.
- Некоторые инструменты ждут `.agentsignore` или `.aiignore` — используйте
  имя, которое читает ваш агент. Содержимое одинаковое.
- Формат как у `.gitignore`: `*`, `?`, `**`, `!`, комментарии `#`.
- Файл коммитится: правила общие для всех, кто работает с проектом.

## OpenCode

OpenCode V2 не читает `.agentignore`: такого поля в конфиге нет. Для него
правила переносятся в `permissions` с `action: "read"` (пример — в README
goskills). `.agentignore` нужен инструментам, которые его поддерживают;
`instructions` и `references` его не применяют, а только показывают текст
агенту.

## Что закрывать

| Категория | Примеры |
|---|---|
| Секреты и доступы | `.env*`, `*.key`, `*.pem`, `.ssh/`, `kubeconfig*` |
| Инфраструктура | `*.tfstate`, `*.tfvars`, `*.ovpn` |
| Данные | dumps, backups, `*.sqlite`, `*.db`, `*.parquet` |
| Реальные данные тестов | `testdata/real/`, `fixtures/real/` |
| Сборка и зависимости | `bin/`, `node_modules/`, `dist/`, `vendor/` |
| Логи и временные файлы | `*.log`, `logs/`, `tmp/`, `.cache/` |
| IDE и ОС | `.idea/`, `.vscode/`, `.DS_Store` |
| Артефакты ИИ-инструментов | `.claude/`, `.cursor/`, `.aider*` |

Не закрывать:

- исходный код и `go.mod`;
- `Makefile`, `README.md`, `AGENTS.md`;
- `configs/.env.example` — шаблон без секретов;
- `api/`, `docs/`, `migrations/`, тесты.

## Важно

`.agentignore` — **не граница безопасности**. Shell-команды (`cat .env`,
`grep -r`) обходят его. Секреты не должны лежать в репозитории вообще:

- продублировать правила в `.gitignore`;
- добавить pre-commit с `gitleaks`;
- хранить секреты в Secret/env, а не в файле.

## Порядок

1. Скопировать `references/.agentignore` в корень проекта.
2. Дополнить путями конкретного проекта (выгрузки, реальные данные).
3. Убедиться, что шаблон конфига не закрыт:

```text
configs/.env.example   # не игнорируется
configs/.env.local     # игнорируется
```

4. Проверить, что агент видит файл: список игнорируемых путей в интерфейсе
   инструмента или тестовый запрос к файлу из списка.

## Эталон

Готовый файл — `references/.agentignore`. Скопировать в корень проекта и
адаптировать. В репозитории goskills он лежит в корне как `.agentignore`.

## Границы

- «Что не коммитить» — `skills/gitignore`.
- «Где лежит конфиг» — `skills/project-structure`, `skills/config`.
- «Какие команды у проекта» — `skills/makefile`.
